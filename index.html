// NOTE 01 · 看片方法

公路片的三个标准动作

上路、迷路、抵达。几乎所有公路片都遵循这个结构，区别在于迷路的原因和抵达时的变化。看懂这三个节点，就能看懂一部公路片在讲什么。

— 老司机 · 看片手记
// NOTE 02 · 选片指南

按路况选片，不踩空

心情差就选公路喜剧，想独处就选治愈系慢车，需要提神就选竞速与追逐。把心情当导航，片单就不会选错。

— 老司机 · 选片指南
// NOTE 03 · 进阶

车厢里的镜头语言

为什么公路片总爱拍挡风玻璃？因为那是最便宜也最有力的"画框中的画框"——前路、后视镜、侧窗，三个视角就能讲完一整段旅程。

— 老司机 · 进阶解读
